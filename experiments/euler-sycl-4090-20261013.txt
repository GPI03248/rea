完整逆向障碍：实测证据
1. REA 成功识别外层 x86_64 ELF，报告 820 个过程；本实验选定并成功反编译 7 个函数，未声称恢复全部 820 个过程。
2. 从 SYCL offload 数据中提取 5 个 EM_CUDA=190 ELF 镜像，NVIDIA cuobjdump 成功解析；含 55 个 SASS 函数条目。
3. REA 对原始 image_01.cubin 返回：unsupported ELF header version。
4. 仅对诊断副本将 NVIDIA e_version 0x79 改为 ELF 1 后，REA 返回：unsupported ELF architecture。原始镜像未修改，诊断副本从未用于运行或性能测试。
5. 原始反编译文本直接交给 icpx 做语法检查失败：undefined8、未恢复的 C++ 类型/调用约定等。日志：analysis/raw-recompile-diagnostics.txt。
6. 当前 Ghidra 安装中未找到 CUDA/PTX/NVIDIA processor 模块。未将其误标为 x86 来强行分析。
因此，仅恢复 CPU 外壳、保留原 GPU 二进制，不能算完成完整 GPU 代码逆向重编译；本次也没有这样伪装结果。

局部重建的准确范围
从实际二进制中经 REA 取得：
  linear_5th_P @ 0x41cbb0
  linear_5th_M @ 0x41cc00
直接保留伪代码的浮点常数与运算括号，不从原函数源码抄写实现。
prepare_partial.py 仅将这两个函数的定义替换为恢复文本，其余求解器源代码继续使用用户提供的源码。
随后用同样的 SYCL 编译器为 GPU 重新编译整个混合来源项目；这属于 CPU 反编译结果重新编译至 GPU 的局部实验，不是 CUDA SASS 全量反编译。
5 个 GPU 镜像中，1 个发生变化，另 4 个逐字节相同；详见 binary-comparison.json。
